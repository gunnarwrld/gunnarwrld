## Selected work

### Ledger Forge — financial systems

A personal Kotlin and Spring Boot project exploring a double-entry wallet ledger. Money is represented in integer minor units; transfers are idempotent; ordered PostgreSQL row locks protect concurrent balances. PostgreSQL integration tests run in CI.

[Repository](https://github.com/gunnarwrld/ledger-api)

### HKIF — backend contribution on a student team

HKIF is a sports-activity platform for students at Kristianstad University. I contributed to the shared backend—not the whole product—including JWT authentication and role hierarchy, the API integration-test harness, and schedule endpoints.

[Auth](https://github.com/jasminerezai/hkif-web/pull/38) · [Roles](https://github.com/jasminerezai/hkif-web/pull/44) · [API tests](https://github.com/jasminerezai/hkif-web/pull/105) · [Schedule API](https://github.com/jasminerezai/hkif-web/pull/133) · [Repository](https://github.com/jasminerezai/hkif-web)

### Fútbol Data Aggregator API — football data backend

A TypeScript and Express API for ingesting API-Football data into PostgreSQL. The repository documents BullMQ workers, Redis-backed rate limiting, and Socket.IO match updates.

[Repository](https://github.com/gunnarwrld/futbol_data_aggregator_api)

### Predicting football scores — applied ML in Group 28

For DA380A, I contributed the Random Forest tuning and time-series evaluation work in a merged pull request. In our team's 90-match CONMEBOL test set, scratch linear regression scored RMSE 1.109 goals versus 1.139 for the tuned forest; both beat the venue baseline (1.196). The result is a comparison, not a claim that one model wins everywhere.

[Project](https://github.com/larrymijo/Project_machine_learning) · [My contribution: PR #5](https://github.com/larrymijo/Project_machine_learning/pull/5) · [Final scores](https://github.com/larrymijo/Project_machine_learning/blob/main/results/final_scoreboard.csv)
